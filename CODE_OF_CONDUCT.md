# Code of Conduct

This is a small project, so the rules are short.

* Be kind, and assume good faith.
* Argue about the code, not the person.
* No harassment, insults or personal attacks.
* Do not post anyone's private information. That includes a private conversation and an API key.

The maintainer may edit or remove comments, close issues and pull requests, and block accounts that break these rules.

## Reporting a problem

Use **Report content** in the menu of the comment, issue or pull request. Reports are private. Please do not argue it out in the thread.

For a security problem, follow [SECURITY.md](SECURITY.md) instead.
